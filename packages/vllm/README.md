# Jev Runtime for vLLM

Native vLLM endpoint integration for
[Jev Runtime](https://github.com/LLM-Perf/jev-runtime), which turns model scores
into versioned typed decisions with probabilities.

Install this package in the same environment as a supported vLLM release:

```bash
pip install jev-vllm
```

Follow the
[vLLM quick start](https://github.com/LLM-Perf/jev-runtime#quick-start)
for engine installation, configuration, and a runnable request.
