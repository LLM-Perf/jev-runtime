# Jev Runtime for SGLang

Native SGLang integration for [Jev Runtime](https://github.com/LLM-Perf/jev-runtime),
which turns model scores into versioned typed decisions with probabilities.

Install this package in the same environment as a supported SGLang release:

```bash
pip install jev-sglang
```

Follow the
[SGLang quick start](https://github.com/LLM-Perf/jev-runtime/blob/main/docs/quickstart-sglang.md)
for engine installation, configuration, and a runnable request.
